KOREKSI JUDUL FORMULIR RAJAWALI EVENT ORGANIZER

Isi paket:
- event.html
- event.js

Perubahan yang dilakukan hanya:
1. event.html: menghapus heading luar "Daftar Event" yang menggandakan judul formulir.
2. event.js: menghapus eyebrow yang berulang di dalam formulir dan mengganti heading "Daftar Event" menjadi "Pendaftaran Peserta".

Bagian lainnya pada salinan event.js dipertahankan tanpa pengubahan.

Cara pemasangan:
1. Cadangkan file event.html dan event.js yang sekarang.
2. Ganti kedua file pada folder utama website dengan file dari paket ini.
3. Jangan mengganti file lain.
4. Setelah unggah, muat ulang halaman dengan refresh penuh agar versi JavaScript terbaru terbaca.
