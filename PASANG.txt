PERBAIKAN FINAL — HAPUS EVENT KAPAN SAJA

Kebijakan baru:
- Admin dapat menghapus event kapan saja, baik Draft, Published, sedang berlangsung, maupun sudah selesai.
- Tidak ada penghapusan otomatis.
- Penghapusan hanya dapat dilakukan oleh akun yang lolos pemeriksaan is_organizer_admin().
- Penghapusan bersifat permanen: data anak yang memiliki foreign key ON DELETE CASCADE ikut terhapus.
- File Storage yang tercatat pada event_assets dihapus terlebih dahulu. Jika penghapusan file gagal, event database tidak diteruskan untuk dihapus.

PASANG FILE
1. GitHub repository root: ganti admin.js dengan file admin.js dari paket ini.
2. Supabase Dashboard > Edge Functions > delete-event > Code: ganti seluruh isi index.ts dengan file supabase/functions/delete-event/index.ts dari paket ini.
3. Tekan Deploy updates pada Supabase.
4. Buka ulang Panel Admin (refresh), login kembali jika diminta, lalu tombol Hapus akan tersedia untuk semua event.

CATATAN KEAMANAN
- Fungsi memeriksa sesi login dan hak Admin di server.
- Jangan menaruh service_role key di HTML, JavaScript browser, atau GitHub.
- Sebelum menghapus event penting, ekspor/backup data bila mungkin.
- Pastikan semua unggahan event tercatat di event_assets agar file Storage dapat ikut dibersihkan.

Jika muncul kegagalan, admin.js sekarang akan menampilkan pesan error asli dari Edge Function, bukan hanya pesan non-2xx.
